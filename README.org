#+title: drop

Share files at web URLs that expire.  A formalized ~see~ / ~eggs~.

#+begin_example
drop put talk.pdf                       # <url>/<hash>/talk.pdf, empty index.html, 7d
drop put pic.jpg --hash file --ttl 2d   # <url>/<hash>.jpg, EXIF stripped
drop put a b -n bundle --index open     # <url>/<hash>-bundle/ with listing
drop put notes.pdf --hash none -n bnl --auth --ttl never
drop put draft.pdf -u alice             # only alice, new users get a generated password
drop passwd add|rm|ls|prune             # users of the target's htpasswd
drop ls -l
drop extend <id> 2w
drop rm <id-or-url>
drop gc [-n]
drop setup systemd|cron [--print]
#+end_example

A target is a directory served by a web server: local, or ~host:path~
reached by ssh and rsync.  Configure targets in ~~/.config/drop/config.toml~.

Each drop is described by a sidecar ~.htdrop-<id>.json~ in the top of the
target directory.  Apache refuses ~.ht*~ files by default so these are not
served.  ~ls~ and ~gc~ read only the sidecars, so ~gc~ may run on the web
host itself (target configured with a local path) or from elsewhere over ssh.

A server that admits only some file types (eg only ~.html~) needs ~grant =
true~ on the target: drop then keeps a top ~.htaccess~ admitting every file
but dotfiles, unless an ~.htaccess~ drop did not write is already there.
~--auth~ drops repeat their ~Require~ in a ~FilesMatch~ and set ~Satisfy
All~, so no grant above them admits without a login.

Options:

- ~--hash dir|file|none~ :: a hash names a directory holding the files, the file itself, or nothing (~--name~ required)
- ~--index empty|open~ :: an empty ~index.html~ blocks listing; ~open~ relies on the server allowing listings
- ~--auth~ :: ~.htaccess~ basic auth using the target's ~htpasswd~ (needs ~AllowOverride AuthConfig~)
- ~--user NAME~ :: implies ~--auth~ with ~Require user NAME~ instead of ~valid-user~
- ~--ttl~ :: 30m, 12h, 7d, 2w or never

~drop passwd~ edits the target's ~htpasswd~ (over ssh for a remote target;
passwords are hashed locally by ~htpasswd~ or ~openssl~).  ~ls~ and ~prune~
scan the ~.htaccess~ files under the target's ~htaccess_root~ (default: the
drop directory's parent, eg ~~/public_html~) for ~Require user~ lines that
use this ~htpasswd~.  ~prune~ offers to remove users none of them name.
Files with ~Require valid-user~ (eg myweb's protected pages) admit any user,
so ~prune~ notes them and defaults to "no" when there are any.
